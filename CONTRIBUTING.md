# Contributing

Thanks for your interest in SSHeesh!

## Ideas and bugs: yes, please

- **Feature requests** are very welcome. [Open one here](https://github.com/footprintsntrails/ssheesh/issues/new?template=feature_request.yml). The best ones describe the problem you hit, not only the solution.
- **Bug reports** help a lot, especially with steps to reproduce. [Report a bug](https://github.com/footprintsntrails/ssheesh/issues/new?template=bug_report.yml).

## Code: not accepted

SSHeesh's code is open, so anyone can read, run and learn from it. Development, though, follows one person's vision for the product, so **pull requests aren't accepted** and are closed automatically. Please open an issue instead; good ideas from issues regularly make it into the app.

You're free to fork it for non-commercial use under the [CC BY-NC-SA 4.0 license](LICENSE): credit the project, keep it non-commercial, and publish your changes under the same license.
